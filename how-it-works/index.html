Notes from Little Wonder

How it works

One small discovery. Every day.

“Open today’s wonder” chooses a discovery using your device’s local calendar date and the ordered collection. Everyone on the same calendar date with the same collection version receives the same wonder. It changes after local midnight, not with each refresh. Adding discoveries may change the sequence; the sixty launch readings repeat after sixty days.

Follow a thread

The Reading Shelf searches titles and keywords locally in your browser. Choose a collection, or use “Surprise me” to pick at random. Surprise avoids the last selection when another wonder is available. Each discovery has its own permanent link and can be read without the book animation.

Keep what stays with you

Save a discovery to My Little Collection. Your favourites live only in this browser on this device. Export a JSON backup to move them elsewhere, then import it on another device. Imports merge with your existing collection. Clearing site data can erase saved favourites.

Nothing to sign up for

No accounts, paid services, tracking scripts, or external image services. The website and all its reading content are served as ordinary files by GitHub Pages. Reading works without JavaScript; interactive features need it.
